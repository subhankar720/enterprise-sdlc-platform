# F-monorepo-foundation-004

## Feature

Planning and skills operating system

## Epic

[EPIC-monorepo-foundation](../epics/EPIC-monorepo-foundation.md)

## Outcome

Lifecycle and domain skills provide consistent, activation-aware instructions
that align with the charter and approved backlog.

## Scope

Standard charter, skills catalog, skill templates, activation matrix, planning
templates, backlog hierarchy, and drift review cadence.

## Dependencies

- None for documentation; skills are refined alongside implementation evidence.

## Acceptance criteria

- Given a lifecycle or domain listed in the skills catalog, When the link is
  followed, Then a skill file exists with trigger, checklist, gates, anti-patterns,
  and done conditions.
- Given a change that spans lifecycle and language domains, When the activation
  matrix is applied, Then both applicable skills are identified.
- Given a conflict between a skill and the standard charter, When the conflict
  is detected, Then the contributor is directed to raise a drift issue or ADR.
- Given a quarterly review, When the charter is compared with repository behavior,
  Then discrepancies have an owner and due date.
